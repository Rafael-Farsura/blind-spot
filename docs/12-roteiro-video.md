# Roteiro do vídeo de entrega (≤ 4 min)

1. **Objetivo (≤ 60s)**  
   “Blind Spot mostra o ponto cego da rotina fiscal: o analista roda uma checagem, vê as inconsistências em cards, comenta e fecha com parecer.”

2. **API / Swagger (60–90s)**  
   - POST job  
   - POST executar  
   - GET inconsistências  
   - PATCH com parecer  
   - (opcional) DELETE

3. **Front (60–90s)**  
   Mesmo fluxo no SPA: criar → executar → abrir card → comentar → resolver. Mostrar que `index.html` abre direto no browser.

4. **Encerrar**  
   Links dos repos api e web.

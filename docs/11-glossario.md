# Glossário

| Termo | Significado |
|-------|-------------|
| Blind Spot | Ponto cego fiscal — inconsistência que a rotina não enxergou |
| Job | Execução registrada de uma checagem |
| Checagem | Processo (simulado no MVP) que gera inconsistências |
| Inconsistência | Achado a triar (divergência, CNPJ, campo, etc.) |
| Parecer | Texto obrigatório ao resolver/descartar |
| Competência | Período de referência (ex.: 2026-07) |
| Seed | Carga inicial para demonstração |
